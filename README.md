# Student Life Dashboard

A web app that helps university students manage courses, deadlines, exams, their
weekly timetable, grades/GPA and study time in one place.

> **Current status: Stage 1 of 8.** The app shell and dashboard work with
> **clearly labeled sample data** (demo mode). Nothing is saved yet. Accounts and
> a real database (Supabase) arrive in Stage 2.

## Tech stack

| Concern | Tool |
| --- | --- |
| UI framework | React 19 + TypeScript, built with Vite |
| Styling | Tailwind CSS v4 + shadcn/ui components (`src/components/ui`) |
| Icons / charts | Lucide React / Recharts |
| Routing | React Router |
| Dates | date-fns |
| Tests | Vitest |
| Database & auth (Stage 2+) | Supabase (PostgreSQL, Auth, Row Level Security) |
| Forms (Stage 3+) | React Hook Form + Zod |

## Getting started

Prerequisites: [Node.js](https://nodejs.org/) 20.19+ or 22.12+ (developed on Node 24).

```bash
npm install       # install dependencies
npm run dev       # start the dev server at http://localhost:5173
```

## Project structure

```
src/
  components/          Reusable UI pieces
    ui/                shadcn/ui primitives (Button, Card, Select, …), generated by the shadcn CLI
    dashboard/         Dashboard widgets (stat cards, deadlines, chart, …)
    layout/            Sidebar navigation
  config/              App-wide config (navigation links)
  hooks/               React hooks (data loading, current time)
  layouts/             Page shells (sidebar + content area)
  lib/                 Business logic: pure, framework-free, unit-tested
    dashboard-stats.ts   Dashboard numbers (pending, overdue, weekly study time, …)
    gpa.ts               Credit-weighted GPA with explained exclusions
    demo-data.ts         Sample data for demo mode
  pages/               One file per route
  types/database.ts    TypeScript shapes of database rows
  utils/               Small formatting helpers
  router.tsx           Route table
```

**Key design decision:** calculations live in `src/lib` as *pure functions*
(input in, result out; no React, no database, and the current time is passed in).
The dashboard calls them with demo data today and will call the same functions
with real Supabase data later, so the tested logic doesn't change.

## How GPA is calculated

```
GPA = sum(grade points × credits) / sum(credits)
```

- Only courses with a **finalized** result that has grade points and more than 0 credits count.
- Every excluded course is reported with a reason (no result, not finalized, missing points, 0 credits).
- If nothing qualifies, the app shows **"Insufficient data"**, never a misleading 0.00.

## Known limitations (Stage 1)

- All data is sample data held in memory; nothing is saved, and there is no sign-in yet.
- Pages other than the dashboard are labeled placeholders.
- Times use the browser's local timezone. A per-user timezone setting comes with Settings.
- The production JS bundle is ~880 kB (mostly the chart library); code-splitting is planned for Stage 8.
